## Wrok Bot 简介 / What is Wrok Bot

Wrok Bot 是用 Rust 构建的 AI 员工 / 数字同事平台，提供能独立完成工作的 AI 同事，包含桌面宿主、服务端、Web 界面与开发中的移动端，首个发布平台为 macOS。项目正在开发与验证中。

Wrok Bot is an AI employee / digital teammate platform built with Rust — AI coworkers who get work done independently. It includes a desktop host, server, web interface and a mobile client in development, with macOS as the first release platform. The project is under active development and validation.
